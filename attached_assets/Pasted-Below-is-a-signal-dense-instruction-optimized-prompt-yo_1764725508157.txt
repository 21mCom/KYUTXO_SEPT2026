## 1. Channel Open Detection (Funding TX)

Classify a transaction as a *likely Lightning channel open* using multiple detection signals.
Each signal increases the probability score.

### **Strong Signals (High Weight)**

* Output is **P2WSH** whose redeemScript matches the canonical LN format:
  `2 <33B pubkey> <33B pubkey> 2 OP_CHECKMULTISIG`
* Funding script matches known patterns for LND, CLN, Eclair.
* **Exactly 1 output** (or 1 primary output + small change).
* Amount typically between **50k–10M sats**.
* The funding TXID appears in **Lightning gossip channel_announcement** as a `short_channel_id` (if gossip is available).

### **Medium Signals (Moderate Weight)**

* Single **P2TR** output with small value (Taproot LN channels).
* TX has **1 input, 1 output**.
* No mempool ancestor UTXOs linked to mixing or typical wallet behaviors.
* Round amounts (e.g., 1M, 2M, 5M sats).

### **Weak Signals (Low Weight)**

* Transaction resembles known LN-node patterns from heuristics.
* Timing aligns with node connect/open events (if available).
* Unusual UTXO consolidation behavior (LN nodes often use sweeping patterns).

Output a final score:
`OpenProbability = weighted_sum(signals) from 0–100%`.

---

## 2. Cooperative Close Detection

Detect cooperative closes (mutual agreement).

### **Strong Signals**

* Input is a known or suspected **LN funding UTXO**.
* Outputs = **exactly two** spendable addresses (P2WPKH, P2TR, P2WSH).
* No timelocks, no penalty paths.

### **Medium Signals**

* Two outputs of moderately sized values compared to channel open amount.
* No OP_CSV / OP_CLTV in the script.

### **Weak Signals**

* The transaction was broadcast shortly after a channel_update in gossip.

Probability:
`CoopCloseProbability = weighted_sum(signals)`.

---

## 3. Force Close Detection

Commitment transactions have unique patterns.

### **Strong Signals**

* Spending a known LN funding UTXO.
* Output contains a **to_local** script:
  `OP_IF <revocationkey> OP_ELSE <CSV delay> OP_CHECKSEQUENCEVERIFY ...`
* HTLC-success or HTLC-timeout scripts present.
* Multiple outputs with OP_CSV / OP_CLTV.

### **Medium Signals**

* A single CSV-delayed output + a normal output.
* Transaction fees unusually high (LND anchors).

### **Weak Signals**

* Followed by child transactions spending CSV outputs.

Probability:
`ForceCloseProbability = weighted_sum(signals)`.

## 4. Unknown / Possibly LN-Related

Use when patterns are incomplete.

### Signals

* TX resembles LN funding (1in/1out, P2WSH/P2TR, small value) but script is unavailable.
* Taproot key-path spending obscures script data.
* Timing aligns with LN node adjacency data.

Output a soft score:
`UncertainLightningProbability = weighted_sum(signals)`.

For any given transaction:

3. Select the **most probable classification**.
4. Include a short explanation describing which signals triggered.
5. If two probabilities are close, output both.
6. Never output absolute certainty unless script patterns match exactly.
